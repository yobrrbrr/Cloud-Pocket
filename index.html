เปิดไฟล์นี้ด้วย text editor แล้วแก้ไขส่วน FIREBASE_CONFIG ด้านบน

วิธีรับ config:

1. ไปที่ console.firebase.google.com

2. สร้าง Project ใหม่ (ฟรี)

3. เพิ่ม Web App → คัดลอก firebaseConfig

4. เปิด Firestore Database → สร้าง (production mode)

5. Authentication → เปิด Google Sign-in

แล้ววาง config ลงในไฟล์นี้แทน YOUR_API_KEY ฯลฯ
